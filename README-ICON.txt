SQL Server BAK Batch Restore - Icon Build

1. Double-click Build-EXE.bat.
2. Build-EXE.bat compiles Source\Program.cs with /win32icon:SqlBatchRestore.ico.
3. The result is SqlBatchRestore.exe with the icon embedded.
4. Only the EXE is needed for normal use. The ICO is a build-time asset.
5. If Windows Explorer shows the old icon after replacing an existing EXE, refresh Explorer or change the filename (Windows icon cache).

Based on v1.0.7, with application icon integration only.
